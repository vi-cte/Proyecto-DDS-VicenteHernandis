# Proyecto DDS - Vicente Hernandis

Este repositorio contiene el desarrollo del proyecto para la asignatura de **Diseño de Sistemas (DDS)**. A continuación se presentan los enlaces directos a las diferentes etapas del desarrollo organizadas por ramas (branches).

## 🚀 Entregas y Sprints

Para facilitar la revisión y evaluación del proyecto, puedes acceder rápidamente a las distintas versiones utilizando los siguientes enlaces:

* **[🔗 Sprint 1 (Rama Main)](https://github.com/vi-cte/Proyecto-DDS-VicenteHernandis/tree/main)**: Contiene la base del proyecto, el análisis inicial y las primeras funcionalidades correspondientes al primer sprint.
* **[🔗 Sprint 2](https://github.com/vi-cte/Proyecto-DDS-VicenteHernandis/tree/sprint-2)**: Contiene los avances de la segunda etapa, incluyendo nuevas características, mejoras y correcciones. 

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Java
* **Herramientas/Frameworks:** PostgreSQL

## 🔧 Instrucciones para cambiar de Sprint en Local

Si deseas probar el código de un sprint específico en tu máquina local, sigue estos pasos:

1.  **Clona el repositorio:**
    ```bash
    git clone [https://github.com/vi-cte/Proyecto-DDS-VicenteHernandis.git](https://github.com/vi-cte/Proyecto-DDS-VicenteHernandis.git)
    cd Proyecto-DDS-VicenteHernandis
    ```

2.  **Muévete a la rama que deseas revisar:**
    * Para ver el Sprint 1: 
      ```bash
      git checkout main
      ```
    * Para ver el Sprint 2: 
      ```bash
      git checkout sprint-2
      ```
